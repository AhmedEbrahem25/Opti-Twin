## ١. نظرة عامة

**Opti-Twin** هو نظام توأم رقمي صناعي يستخدم تعلم التعزيز متعدد الأهداف (MORL) لتحسين استهلاك الطاقة في أفران الصهر الكهربائية (EAF) في مصانع الصلب المصرية.

**المصنع المستهدف:** إيزي للصلب المسطح — مجمع عين السخنة، مصر  
**الفرن المستهدف:** فرن EAF رقم 2 بطاقة 185 طن (1.6 مليون طن سنوياً)

### ماذا يفعل النظام؟
- 📉 **يخفض تكلفة الكهرباء** بنسبة 5–15% مع الحفاظ على الإنتاج الكامل
- 🤖 **يتخذ قرارات ذكية** في الوقت الفعلي ويشرحها بالعربية والإنجليزية
- ⚡ **يستجيب لأسعار الطاقة** ديناميكياً ويشارك في برامج الاستجابة للطلب
- 🌡️ **يراقب صحة الفرن** ويتجنب الأعطال

## ٣. شريط المؤشرات الرئيسية

يظهر في أعلى الصفحة ويحتوي على 6 بطاقات:

| البطاقة | الوصف | القيم الطبيعية |
|---------|-------|----------------|
| 💰 **الوفورات اليومية** | إجمالي ما وُفِّر اليوم بالجنيه المصري | يرتفع مع الوقت |
| ⚡ **تكلفة الساعة الحالية** | التكلفة الحالية بالجنيه/ساعة | 800–1400 جنيه |
| 🌡️ **درجة حرارة الحمام** | درجة حرارة الصلب المصهور | 1550–1650°C |
| 📊 **معامل القدرة (PF)** | جودة استهلاك الكهرباء | 0.90–0.95 (المرجع: 0.92) |
| 🔧 **صحة الفرن** | حالة الماكينة | SAFE ✓ / WARNING / CRITICAL |
| 🌱 **CO₂ الموفَّر** | كمية الانبعاثات الكربونية المُجنَّبة | يرتفع مع الوقت |

> **تلميح:** عندما يكون الذكاء الاصطناعي نشطاً، ستلاحظ ارتفاع الوفورات وانخفاض التكلفة تدريجياً.

## ٤. الرسم البياني للطاقة

يعرض في الوقت الفعلي:
- **الخط الأزرق** — قدرة القوس الكهربائي (ميغاواط)
- **الخلفية الحمراء** — فترة ذروة الاستهلاك (18:00–22:00)
- **المحور الأيسر** — القدرة بالميغاواط (0–110)
- **المحور السفلي** — الوقت المحاكى

**ما تبحث عنه:**
- انخفاض القدرة في أوقات الذروة = الذكاء الاصطناعي يعمل بكفاءة ✓
- تذبذبات حادة غير منتظمة = حالة طوارئ

## ٥. مقياس الحرارة

يعرض شريطين:

### حرارة الحمام (Bath Temp)
- **الهدف:** 1550–1650°C
- **اللون الأخضر:** ضمن النطاق الآمن
- **اللون الأحمر:** خارج النطاق — يستدعي انتباهاً

### حرارة جدار الفرن (Wall Temp)
- **الحد الأقصى:** 250°C
- **اللون الأصفر عند:** 180–220°C (تحذير)
- **اللون الأحمر فوق:** 220°C (خطر)

> ⚠️ إذا تحول مقياس الجدار للأحمر، يجب على الذكاء الاصطناعي إطلاق **EMERGENCY_COOLING** خلال دورة واحدة (3 ثوانٍ).

## ٦. بطاقة حالة الفرن

تعرض المعلومات التشغيلية التفصيلية:

| الحقل | الوصف |
|-------|-------|
| **Machine** | معرّف الفرن (EAF_02_EZZ_AIN_SOKHNA) |
| **Phase** | مرحلة التشغيل الحالية مع شريط التقدم |
| **Batches Today** | عدد الدفعات المنتجة اليوم |
| **Grid Hz** | تردد الشبكة الكهربائية (50 هرتز طبيعي) |
| **Electrode** | استهلاك الأقطاب الكهربائية (كيلوغرام/اليوم) |
| **Status** | ON_TRACK ✓ / AT_RISK / BEHIND |

### مراحل تشغيل الفرن
```
CHARGING       → تحميل الخردة
BORE_DOWN      → اختراق الخردة بالقوس
MELTING_PHASE_1 → الصهر الأولي
MELTING_PHASE_2 → الصهر الرئيسي ← أعلى استهلاك للطاقة
REFINING       → تكرير الصلب
TAPPING        → صب الصلب المصهور
IDLE           → وقف بين الدفعات
```

## ٧. سجل قرارات الذكاء الاصطناعي

أهم قسم في لوحة التحكم — يعرض كل قرار اتخذه الذكاء الاصطناعي مع شرح كامل.

### كيفية القراءة

```
18:32  REDUCE_ARC_POWER  ↓15%
"انخفضت قدرة القوس بنسبة 15%. درجة حرارة الحمام 1,623°C — آمنة.
 التسعير في الذروة (2.43 جنيه/كيلوواط). التوفير: 185 جنيه/ساعة."
```

| العنصر | الوصف |
|--------|-------|
| **الوقت** | وقت القرار في التوقيت المحاكى |
| **الإجراء** | نوع القرار (انظر الجدول أدناه) |
| **النسبة** | مقدار التغيير (%) |
| **التوفير** | الوفر بالجنيه/ساعة |
| **الشرح** | السبب كاملاً بالعربية أو الإنجليزية |
| **الصحة** | SAFE / WARNING / CRITICAL |
| **الإنتاج** | ON_TRACK / AT_RISK / BEHIND |

### أنواع القرارات

| القرار | المعنى |
|--------|--------|
| `REDUCE_ARC_POWER` | تخفيض قدرة القوس الكهربائي (توفير في الذروة) |
| `INCREASE_ARC_POWER` | رفع القدرة (تسريع الإنتاج عند الحاجة) |
| `RAISE_PF_COMP` | رفع تعويض معامل القدرة (تجنب الغرامة) |
| `LOWER_PF_COMP` | خفض التعويض (توازن الطاقة التفاعلية) |
| `HOLD_CURRENT` | الإبقاء على الإعدادات الحالية |
| `EMERGENCY_COOLING` | تبريد طارئ (درجة حرارة الجدار حرجة) |
| `PRE_PEAK_DROP` | تخفيض استباقي قبل ذروة الأسعار |
| `REDUCE_ARC_POWER` + `dr_curtailment` | تخفيض في إطار برنامج استجابة الطلب |

### تبديل اللغة
- اضغط **EN** لعرض الشرح بالإنجليزية
- اضغط **AR** لعرض الشرح بالعربية

## ٨. لوحة التحكم

تقع في أسفل الشاشة الرئيسية وتحتوي على:

### 🤖 تبديل الذكاء الاصطناعي
```
AI: [ON ●]   ←  الذكاء الاصطناعي نشط
AI: [OFF ○]  ←  الذكاء الاصطناعي معطل (وضع المراقبة فقط)
```
- **تشغيل:** الذكاء الاصطناعي يتخذ القرارات ويرسل أوامر للفرن
- **إيقاف:** النظام يراقب فقط بدون تدخل

### ⏰ وضع التعريفة
```
TOU: [ON ●]   ← تسعير الذروة/خارج الذروة
TOU: [OFF ○]  ← التعريفة الثابتة 1.60 جنيه/كيلوواط
```

### 📋 ملف التحسين
اختر أولوية التحسين من القائمة المنسدلة:

| الملف | الأولوية |
|-------|---------|
| **cost** | توفير الطاقة أولاً |
| **production** | الإنتاج أولاً |
| **balanced** | توازن بين الطاقة والإنتاج |
| **quality** | جودة الصلب أولاً |

### 🚨 حقن الأزمات (للتجربة)
يتيح محاكاة حالات الطوارئ لاختبار استجابة الذكاء الاصطناعي:

| الحدث | ما يحدث |
|-------|---------|
| **wall_overheat** | ارتفاع حرارة الجدار للنطاق الحرج |
| **electrode_break** | كسر قطب كهربائي |
| **grid_spike** | ارتفاع مفاجئ في سعر الكهرباء |
| **transformer_alarm** | إنذار المحول الكهربائي |

> **للتجربة:** اختر حدثاً واضغط Inject → راقب سجل الذكاء الاصطناعي لترى الاستجابة خلال 3 ثوانٍ

## ٩. لوحة التسعير الديناميكي

تقع في أسفل الصفحة وتعرض المحرك المالي للنظام.

### العمود الأول — السعر المباشر
- **الرقم الكبير:** السعر الحالي (جنيه/كيلوواط ساعة)
- **اللون الأخضر:** سعر منخفض (< 1.80 جنيه)
- **اللون الأصفر:** سعر متوسط (1.80–2.20 جنيه)
- **اللون الأحمر:** سعر مرتفع (> 2.20 جنيه)
- **شارة PEAK:** الفترة الحالية في وقت الذروة

**أوضاع التسعير** (القائمة المنسدلة):

| الوضع | الوصف |
|-------|-------|
| **Flat (1.60 EgyptERA)** | التعريفة الثابتة الرسمية |
| **TOU Schedule** | ذروة 2.50 / خارج ذروة 1.20 جنيه |
| **Spot (Synthetic)** | سوق فوري محاكى مع تقلبات واقعية |

### العمود الثاني — توقعات الأسعار
- **الأشرطة الخضراء:** أسعار منخفضة (خارج الذروة)
- **الأشرطة الحمراء:** أسعار مرتفعة (ذروة)
- يعرض التوقعات للـ 4 ساعات القادمة (8 أشرطة × 30 دقيقة)
- **Max / Min:** أعلى وأدنى سعر متوقع

> 💡 الذكاء الاصطناعي يرى هذه التوقعات ويخفض الطاقة **قبل** وصول الذروة (قرار PRE_PEAK_DROP)

### العمود الثالث — مصادر الإيرادات
يعرض 4 مصادر دخل متراكمة اليوم:

| المصدر | الوصف |
|--------|-------|
| **Energy Savings** | وفورات مباشرة من تخفيض الاستهلاك |
| **DR Payments** | مدفوعات برامج الاستجابة للطلب |
| **Capacity Credits** | عائد سوق الطاقة الاحتياطية |
| **Ancillary** | خدمات مساندة الشبكة |

### العمود الرابع — الاستجابة للطلب (DR)
**حقن حدث DR:**

| النوع | المعدل |
|-------|--------|
| **Curtailment** | 250 جنيه/ميغاواط ساعة |
| **Interruptible** | 450 جنيه/ميغاواط ساعة |
| **Frequency Response** | 950 جنيه/ميغاواط ساعة |

- **ACCEPTED ✓** — الذكاء الاصطناعي قبل الحدث وكسب المدفوعات
- **declined ✗** — رفض الحدث (مرحلة غير آمنة للتخفيض)

**توفير الجدولة:** يعرض مقدار التوفير من إعادة جدولة الدفعات لتجنب ساعات الذروة.

## ١٠. سيناريو العرض التوضيحي

### العرض الكامل (3 دقائق)

**الدقيقة 0:00–0:45 — الوضع الأساسي**
1. افتح http://localhost:3000
2. لاحظ الساعة المحاكاة تقترب من 18:00 (بداية الذروة)
3. أشر إلى تكلفة الساعة الحالية: ~1,240 جنيه/ساعة
4. الذكاء الاصطناعي **معطل** — النظام يراقب فقط

**الدقيقة 0:45–1:15 — دخول الذروة**
1. انتظر حتى الساعة 18:00 في العداد المحاكى
2. لاحظ تحول السعر: 1.60 ← 2.43 جنيه/كيلوواط
3. بطاقة التكلفة تتحول للأحمر

**الدقيقة 1:15–2:00 — تفعيل الذكاء الاصطناعي**
1. اضغط **AI: [ON ●]** في لوحة التحكم
2. راقب سجل القرارات — يتعبئ فوراً:
   ```
   REDUCE_ARC_POWER ↓15%
   "التسعير في الذروة. حرارة الحمام آمنة. توفير 185 جنيه/ساعة"
   ```
3. الرسم البياني يُظهر انخفاض القدرة
4. الوفورات اليومية تبدأ بالارتفاع
5. **جرب:** اضغط AR لعرض الشرح بالعربية

**الدقيقة 2:00–2:30 — حقن أزمة**
1. في لوحة التحكم: اختر **wall_overheat** ← اضغط Inject
2. مقياس الجدار يتحول للأحمر (185°C → 210°C)
3. الذكاء الاصطناعي يرد بـ **EMERGENCY_COOLING** خلال دورة واحدة
4. الشرح: "درجة حرارة الجدار حرجة. تبريد طارئ مفعّل."
5. الحرارة تنخفض تدريجياً خلال دورتين
6. الحالة: WARNING → SAFE

**الدقيقة 2:30–3:00 — النتائج النهائية**
```
⚡ توفير الطاقة     ↓18%
🏭 الإنتاج          100%
🌡️ صحة الفرن       SAFE ✓
💰 وُفِّر اليوم     2,340 جنيه
🌱 CO₂ مُجنَّب      125 كيلوغرام
```

### عرض التسعير الديناميكي (دقيقتان إضافيتان)

1. انتقل للوحة التسعير الديناميكي في الأسفل
2. غيّر الوضع إلى **Spot (Synthetic)**
3. لاحظ تغير السعر للسوق الفوري
4. أشر إلى توقعات الـ 4 ساعات القادمة
5. افتح قائمة **Inject DR event** ← اختر **Frequency Response**
6. راقب قسم "Recent DR" — ستظهر:
   - ACCEPTED ✓ مع مدفوعات 950 جنيه/ميغاواط
7. لاحظ ارتفاع DR Payments في مصادر الإيرادات

## ١١. الأسئلة الشائعة

**س: لماذا لا تتحرك البيانات؟**  
ج: تحقق من مؤشر الاتصال في أعلى اليمين. إذا كان أحمر، افتح http://localhost:8000/docs للتحقق من الخادم.

**س: ما معنى PF penalty؟**  
ج: هيئة تنظيم الكهرباء المصرية (EgyptERA) تفرض غرامة إذا انخفض معامل القدرة عن 0.92. الذكاء الاصطناعي يرفع التعويض التفاعلي لتجنبها.

**س: ما الفرق بين التعريفة الثابتة والسوق الفوري؟**  
ج: التعريفة الثابتة = 1.60 جنيه/كيلوواط دائماً. السوق الفوري = يتغير كل 30 دقيقة بين 1.35 و2.50 جنيه حسب الطلب.

**س: لماذا يرفض الذكاء الاصطناعي أحياناً أحداث DR؟**  
ج: في مراحل معينة (TAPPING, BORE_DOWN, CHARGING) لا يمكن تخفيض الطاقة بأمان. النظام يحمي الإنتاج والجودة أولاً.

**س: كيف أوقف التطبيق؟**  
```bash
docker compose down
```

**س: كيف أعيد ضبط الإحصاءات اليومية؟**  
```bash
docker compose restart
```
