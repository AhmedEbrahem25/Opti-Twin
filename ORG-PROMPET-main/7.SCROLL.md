# MODULE: SCROLL SYSTEM
**ID:** 06 | **Load order:** 6 | **Depends on:** ANIMATION, TECH-STACK | **Required:** always

---

## RESPONSIBILITY
Configure Lenis smooth scroll (physics, velocity, GSAP sync) and Barba.js page transitions.  
This module owns all scroll physics and between-page navigation behavior.

## SCOPE BOUNDARIES
- ✅ Lenis initialization and configuration
- ✅ Lenis ↔ GSAP ticker synchronization
- ✅ Scroll velocity CSS variable (`--scroll-velocity`)
- ✅ Barba.js setup: blur-scale transition, view hooks, after-hooks
- ❌ Does NOT define what animates on scroll (→ ANIMATION module)
- ❌ Does NOT define navbar scroll behavior (→ NAVBAR module)
- ❌ Does NOT define parallax layers (→ ANIMATION module)

## WHEN TO USE
Every project that has scrollable content or multiple pages.

## WHEN NOT TO USE
Single-screen apps (no scroll) + no page navigation — skip Lenis and Barba.  
If no page transitions — skip Barba only.

## CONFLICTS
- Do NOT set `scroll-behavior: smooth` in CSS. Lenis owns scroll.
- Do NOT `overflow: hidden` on `body` after Lenis init — breaks smooth scroll.
- Do NOT call `window.scrollY` directly — use `lenis.scroll` or listen to `lenis.on('scroll')`.
- Three.js must use `autoRaf: false` in Lenis config — share the GSAP ticker.

## LENIS INITIALIZATION

```javascript
// ═══════════════════════════════════════════════
//  scripts/scroll.js
// ═══════════════════════════════════════════════

/**
 * initLenis
 * Initializes Lenis with optimized physics.
 * MUST be called before any scroll-dependent code.
 * MUST be called before Barba, ScrollTrigger, or Three.js.
 *
 * @returns {Lenis} — the Lenis instance (also stored as window.__lenis)
 */
function initLenis() {
  const lenis = new Lenis({
    duration:          1.4,
    easing:            (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)), // Expo ease
    direction:         'vertical',
    gestureDirection:  'vertical',
    smooth:            true,
    smoothTouch:       false,   // Native scroll on touch — better feel
    touchMultiplier:   2,
    infinite:          false,
    autoRaf:           false,   // CRITICAL: share GSAP ticker, not separate RAF
  });

  // ── Sync with GSAP ticker ──────────────────────
  // This is the single RAF loop — everything shares it.
  // Order: lenis.raf first, then ScrollTrigger.update.
  gsap.ticker.add((time) => { lenis.raf(time * 1000); });
  lenis.on('scroll', ScrollTrigger.update);
  gsap.ticker.lagSmoothing(0);  // Prevent lag accumulation on tab switch

  // ── Expose scroll state as CSS variables ──────
  // --scroll-velocity: used by parallax for depth multiplier
  // --scroll-progress: 0→1 across full page height
  lenis.on('scroll', ({ scroll, velocity, progress }) => {
    document.documentElement.style.setProperty(
      '--scroll-velocity', Math.abs(velocity).toFixed(3)
    );
    document.documentElement.style.setProperty(
      '--scroll-progress', progress.toFixed(4)
    );
  });

  window.__lenis = lenis;   // Global access — used by ThreeEngine and Navbar
  return lenis;
}
```

### Lenis Physics Tuning

| Setting | Value | Effect |
|---|---|---|
| `duration` | `1.4` | Scroll inertia travel time. Lower = snappier. |
| `easing` | Expo curve | Decelerates sharply near rest point — feels physical. |
| `smoothTouch` | `false` | Native scroll on touch — smoother on iOS. |
| `touchMultiplier` | `2` | Increases scroll speed on touch to feel natural. |
| `autoRaf` | `false` | Critical for Three.js coexistence. |

## BARBA.JS — PAGE TRANSITIONS

```javascript
/**
 * initBarba
 * Cinematic page transition system.
 * Transition: blur-scale (current blurs out, next blurs in).
 * Always re-initializes scroll reveals + navbar after transition.
 *
 * MUST be called inside initMainExperience() — never during intro.
 */
function initBarba() {
  barba.init({
    // Don't intercept links with .no-barba class
    prevent: ({ el }) => el.classList.contains('no-barba'),

    transitions: [
      {
        name: 'blur-scale',

        // ── Leave: current page blurs + scales down ──
        leave({ current }) {
          return gsap.timeline()
            .to(current.container, {
              opacity: 0,
              filter:  'blur(16px)',
              scale:   0.96,
              duration: 0.55,
              ease:    'power3.inOut',
            });
        },

        // ── Enter: next page blurs in from above scale ──
        enter({ next }) {
          gsap.set(next.container, {
            opacity: 0,
            filter:  'blur(16px)',
            scale:   1.04,
            y:       20,
          });
          return gsap.timeline()
            .to(next.container, {
              opacity:  1,
              filter:   'blur(0px)',
              scale:    1,
              y:        0,
              duration: 0.75,
              ease:     'power3.out',
            });
        },

        // ── After: re-init scroll system + navbar state ──
        after() {
          ScrollTrigger.refresh();
          initScrollReveal();       // Re-register all [data-reveal] on new page
          updateNavbarForPage();    // Mark correct nav link as active
        },
      },
    ],

    // ── View hooks — page-specific init ──────────
    views: [
      {
        namespace: 'home',
        beforeEnter() { initHeroAnimations(); },
      },
      // Add more view namespaces per page as needed:
      // { namespace: 'work', beforeEnter() { initWorkGrid(); } },
    ],
  });

  // ── Global after hook — always fires after any transition ──
  barba.hooks.after(() => {
    window.__lenis?.resize();   // Recalculate scroll height for new page content
  });
}
```

### Barba View Namespace Setup

In your HTML, mark each page container:

```html
<!-- index.html -->
<div data-barba="container" data-barba-namespace="home">
  <!-- page content -->
</div>

<!-- work.html -->
<div data-barba="container" data-barba-namespace="work">
  <!-- page content -->
</div>
```

The `<body>` tag remains the wrapper:
```html
<body data-barba="wrapper">
```

## RULES — SCROLL SYSTEM

```
✅ Always:
  — Use lenis.scroll instead of window.scrollY
  — Call initScrollReveal() after every Barba transition
  — Call window.__lenis.resize() after dynamic content changes
  — Call ScrollTrigger.refresh() after Barba transitions

❌ Never:
  — scroll-behavior: smooth in CSS (Lenis owns this)
  — overflow: hidden on body after Lenis init
  — Call window.scrollTo() — use lenis.scrollTo() instead
  — Run a second requestAnimationFrame loop
```

## LENIS UTILITY METHODS

```javascript
// Programmatic scroll to element or position
window.__lenis.scrollTo('#section-id', { offset: -80, duration: 1.2 });
window.__lenis.scrollTo(0); // Scroll to top

// Pause/resume scroll (e.g., when mobile menu opens)
window.__lenis.stop();
window.__lenis.start();

// Get current scroll position
const scrollY = window.__lenis.scroll;

// Get current velocity
const velocity = window.__lenis.velocity;
```

## PERFORMANCE IMPACT
- **Lenis:** Very low — runs inside existing GSAP ticker, no additional RAF.
- **Barba:** Low — intercepts link clicks, no persistent overhead. DOM is partially reused.
- **ScrollTrigger.refresh():** Can be expensive on pages with many triggers. Debounce on resize:

```javascript
let refreshTimeout;
window.addEventListener('resize', () => {
  clearTimeout(refreshTimeout);
  refreshTimeout = setTimeout(() => ScrollTrigger.refresh(), 200);
});
```

## IMPLEMENTATION NOTES
- Files: `scripts/scroll.js` (Lenis), `scripts/transitions.js` (Barba)
- `initLenis()` must be called **before** anything scroll-related — step 2 in init order
- `initBarba()` must be called **inside** `initMainExperience()` — not during loading
- Each page's HTML must declare `data-barba="container"` and `data-barba-namespace`
- To prevent a link from being intercepted by Barba: add `class="no-barba"` to the `<a>` tag
