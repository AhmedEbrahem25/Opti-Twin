# MODULE: WEBGL / THREE.JS ENGINE
**ID:** 11 | **Load order:** 11 | **Depends on:** TECH-STACK, ANIMATION, SCROLL | **Required:** 3D projects

---

## RESPONSIBILITY
Full Three.js engine: renderer setup, lighting, GLB model loading (Draco), idle animation,  
mouse-driven rotation, scroll influence, and post-processing hooks.

## SCOPE BOUNDARIES
- ✅ `MODEL_CONFIG` — single source of truth for 3D scene
- ✅ `ThreeEngine` class — scene, camera, renderer, lights, model, render loop
- ✅ GLTFLoader + DRACOLoader setup
- ✅ Mouse interaction and scroll integration via Lenis
- ✅ Post-processing stubs (Bloom, SSAO)
- ✅ Adaptive quality hooks (pixel ratio, shadow map)
- ❌ Does NOT define GLSL shaders inline (large shaders go in `scripts/shaders.js`)
- ❌ Does NOT own the render loop RAF (→ GSAP ticker)
- ❌ Does NOT manage canvas positioning via JS beyond initial setup

## WHEN TO USE
- Portfolio showcasing a 3D model
- Product pages with interactive 3D
- AI/tech sites with abstract 3D scene
- Any site where 3D is a visual differentiator

## WHEN NOT TO USE
- SaaS dashboards — too heavy, wrong context
- Content-heavy editorial sites — 3D competes with reading
- Mobile-first projects — Three.js is expensive on mobile
- When Spline covers the use case (embedded scenes) — prefer Spline for simplicity

## CONFLICTS
- `autoRaf: false` must be set in Lenis — they share the GSAP ticker
- ThreeEngine canvas: `z-index: 1`, `pointer-events: none` — never blocks UI
- Maximum 4 lights in scene — more = GPU pressure
- Never call `requestAnimationFrame` directly in this module

## MODEL CONFIGURATION

```javascript
// ═══════════════════════════════════════════════
//  scripts/config.js — EDIT THIS BLOCK ONLY
//  All other Three.js code reads from MODEL_CONFIG
// ═══════════════════════════════════════════════

const MODEL_CONFIG = {
  path:               './assets/models/YOUR_MODEL.glb', // Only path to change
  autoCenter:         true,         // Center model on bounding box
  autoScale:          true,         // Scale model to fit targetSize
  targetSize:         2.0,          // World units

  cameraPosition:     { x: 0, y: 0, z: 4 },
  fov:                45,

  idleRotationSpeed:  0.003,        // rad/frame
  idleFloatAmplitude: 0.08,         // world units
  idleFloatSpeed:     0.6,          // cycles/sec

  mouseInfluence:     0.12,         // rotation scale factor
  scrollRotationFactor: 0.8,        // rotation from scroll progress
  scrollPositionFactor: 0.5,        // Z-position from scroll progress
};
```

## THREE.JS ENGINE CLASS

```javascript
// File: scripts/three-engine.js

class ThreeEngine {
  constructor(canvasSelector) {
    this.canvas          = document.querySelector(canvasSelector);
    if (!this.canvas) return;
    this.model           = null;
    this.mixer           = null;
    this.clock           = new THREE.Clock();
    this.mouse           = new THREE.Vector2();
    this.targetRotation  = new THREE.Vector2();
    this.currentRotation = new THREE.Vector2();
    this.scrollY         = 0;
    this.time            = 0;
    this.init();
  }

  init() {
    this.setupScene();
    this.setupCamera();
    this.setupRenderer();
    this.setupLights();      // Max 4 lights
    this.loadModel();
    this.bindEvents();
    this.startRenderLoop();  // Plugs into GSAP ticker
  }

  setupScene() {
    this.scene = new THREE.Scene();
    this.scene.fog = new THREE.FogExp2(0x050505, 0.08);
  }

  setupCamera() {
    this.camera = new THREE.PerspectiveCamera(
      MODEL_CONFIG.fov,
      window.innerWidth / window.innerHeight,
      0.01, 1000
    );
    const { x, y, z } = MODEL_CONFIG.cameraPosition;
    this.camera.position.set(x, y, z);
  }

  setupRenderer() {
    this.renderer = new THREE.WebGLRenderer({
      canvas: this.canvas,
      alpha: true,              // Transparent background
      antialias: true,
      powerPreference: 'high-performance',
      stencil: false,
      depth: true,
    });
    this.renderer.setSize(window.innerWidth, window.innerHeight);
    this.renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)); // Cap at 2
    this.renderer.toneMapping = THREE.ACESFilmicToneMapping;
    this.renderer.toneMappingExposure = 1.2;
    this.renderer.outputColorSpace = THREE.SRGBColorSpace;
    this.renderer.shadowMap.enabled = true;
    this.renderer.shadowMap.type = THREE.PCFSoftShadowMap;

    // Canvas positioning — behind all DOM, pointer-events off
    this.canvas.style.cssText = `
      position: fixed; top: 0; left: 0;
      width: 100%; height: 100%;
      z-index: 1; pointer-events: none;
    `;
  }

  setupLights() {
    // Key light (main illumination)
    const key = new THREE.DirectionalLight(0xffffff, 2.5);
    key.position.set(3, 5, 3);
    key.castShadow = true;
    key.shadow.mapSize.set(1024, 1024);
    this.scene.add(key);

    // Fill light (soften shadows)
    const fill = new THREE.DirectionalLight(0x4466ff, 0.8);
    fill.position.set(-3, 2, -2);
    this.scene.add(fill);

    // Rim light (edge definition)
    const rim = new THREE.DirectionalLight(0xffffff, 1.2);
    rim.position.set(0, -2, -4);
    this.scene.add(rim);

    // Ambient (global fill — lowest intensity)
    const ambient = new THREE.AmbientLight(0xffffff, 0.3);
    this.scene.add(ambient);

    // Total: 4 lights. Do not add more.
  }

  loadModel() {
    const dracoLoader = new THREE.DRACOLoader();
    dracoLoader.setDecoderPath('https://www.gstatic.com/draco/versioned/decoders/1.5.6/');

    const loader = new THREE.GLTFLoader();
    loader.setDRACOLoader(dracoLoader);

    loader.load(MODEL_CONFIG.path, (gltf) => {
      this.model = gltf.scene;

      // Auto-center
      if (MODEL_CONFIG.autoCenter) {
        const box    = new THREE.Box3().setFromObject(this.model);
        const center = box.getCenter(new THREE.Vector3());
        this.model.position.sub(center);
      }

      // Auto-scale to targetSize
      if (MODEL_CONFIG.autoScale) {
        const box    = new THREE.Box3().setFromObject(this.model);
        const size   = box.getSize(new THREE.Vector3());
        const maxDim = Math.max(size.x, size.y, size.z);
        this.model.scale.setScalar(MODEL_CONFIG.targetSize / maxDim);
      }

      // Shadows + env map
      this.model.traverse((child) => {
        if (child.isMesh) {
          child.castShadow = true;
          child.receiveShadow = true;
          if (child.material) child.material.envMapIntensity = 1.2;
        }
      });

      // Play first animation if present
      if (gltf.animations.length > 0) {
        this.mixer = new THREE.AnimationMixer(this.model);
        this.mixer.clipAction(gltf.animations[0]).play();
      }

      this.scene.add(this.model);

      // Entrance animation via GSAP
      gsap.from(this.model.position, {
        y: this.model.position.y - 1,
        duration: 1.2, ease: 'power3.out'
      });
    });
  }

  bindEvents() {
    window.addEventListener('mousemove', (e) => {
      this.mouse.x =  (e.clientX / window.innerWidth  - 0.5) * 2;
      this.mouse.y = -(e.clientY / window.innerHeight - 0.5) * 2;
      this.targetRotation.x = this.mouse.y * MODEL_CONFIG.mouseInfluence;
      this.targetRotation.y = this.mouse.x * MODEL_CONFIG.mouseInfluence;
    }, { passive: true });

    window.__lenis?.on('scroll', ({ scroll }) => { this.scrollY = scroll; });

    window.addEventListener('resize', () => {
      this.camera.aspect = window.innerWidth / window.innerHeight;
      this.camera.updateProjectionMatrix();
      this.renderer.setSize(window.innerWidth, window.innerHeight);
    });
  }

  startRenderLoop() {
    // Add to GSAP ticker — unified RAF loop
    gsap.ticker.add((time) => {
      this.time = time;
      const delta = this.clock.getDelta();
      if (this.mixer) this.mixer.update(delta);

      if (this.model) {
        // Lerp rotation toward mouse target (0.08 = lag factor)
        this.currentRotation.x += (this.targetRotation.x - this.currentRotation.x) * 0.08;
        this.currentRotation.y += (this.targetRotation.y - this.currentRotation.y) * 0.08;

        // Idle float (sine wave)
        this.model.position.y = Math.sin(time * MODEL_CONFIG.idleFloatSpeed)
          * MODEL_CONFIG.idleFloatAmplitude;

        // Rotation = idle + mouse
        this.model.rotation.x = this.currentRotation.x;
        this.model.rotation.y += MODEL_CONFIG.idleRotationSpeed + this.currentRotation.y * 0.05;

        // Scroll influence
        const scrollProgress = this.scrollY / document.body.scrollHeight;
        this.model.rotation.y += scrollProgress * MODEL_CONFIG.scrollRotationFactor * 0.01;
        this.model.position.z  = scrollProgress * MODEL_CONFIG.scrollPositionFactor * -1;
      }

      this.renderer.render(this.scene, this.camera);
    });
  }

  // Post-processing stub — activate on HIGH quality tier only
  setupPostProcessing() {
    // Add: UnrealBloomPass for glow, SSAOPass for ambient occlusion
    // Requires: EffectComposer, RenderPass (not in CDN r128 — self-host or skip)
    // Only activate when: AdaptiveQuality.tier === 'HIGH'
  }
}
```

## GLB MODEL REQUIREMENTS

- All models must be Draco-compressed (use `gltfpack` or Blender Draco export)
- Target file size: < 2MB for web delivery
- Max polygon count: 100k triangles for HIGH tier, 30k for MEDIUM
- UV-unwrapped for PBR materials
- Single animation clip preferred (mixer plays index 0)

---

## PERFORMANCE IMPACT
- **High** — Three.js renderer + shadow maps are the heaviest system in FAEA.
- Pixel ratio capped at 2 — prevents 3x DPR render on Retina+ displays.
- `powerPreference: 'high-performance'` requests discrete GPU on laptops.
- Shadow map at 1024×1024 — increase to 2048 only on HIGH tier.
- Disable on mobile: `if (!isMobile) new ThreeEngine('#webgl-canvas');`

## IMPLEMENTATION NOTES
- Files: `scripts/config.js` (MODEL_CONFIG), `scripts/three-engine.js`
- Instantiated inside `initMainExperience()` — desktop only
- `MODEL_CONFIG.path` is the ONLY value to change per project
- Wrap in `AdaptiveQuality` after instantiation (→ PERFORMANCE module)
