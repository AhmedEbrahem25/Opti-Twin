# MODULE: TECH-STACK
**ID:** 04 | **Load order:** 4 | **Depends on:** none | **Required:** always (CDN projects)

---

## RESPONSIBILITY
Define all third-party libraries, their CDN URLs, load order, and coexistence rules.  
Every script used in FAEA is documented here. No library is imported anywhere else without appearing here first.

## SCOPE BOUNDARIES
- ✅ CDN script tags with versioned URLs
- ✅ Library purpose and ownership rules
- ✅ Load order requirements
- ✅ Coexistence rules between libraries
- ❌ Does NOT configure the libraries (→ respective modules)
- ❌ Does NOT explain HOW to use the libraries (→ ANIMATION, SCROLL, WEBGL, etc.)

## WHEN TO USE
Whenever the project uses CDN delivery (no bundler). Provides all script tags.

## WHEN NOT TO USE
If using a bundler (Vite, Webpack, Next.js) — replace CDN scripts with npm packages.  
The coexistence rules still apply regardless.

## LIBRARY OWNERSHIP — WHO OWNS WHAT

| Library | Owns | Does NOT own |
|---|---|---|
| **GSAP** | Scroll-triggered entrances, timelines, SplitText, all JS-driven CSS animations | Smooth scroll physics, SVG paths |
| **Lenis** | Scroll physics, velocity, inertia, `--scroll-velocity` CSS var | Any CSS animation |
| **Anime.js** | SVG `strokeDashoffset`, number counters, grid staggers | Scroll-triggered anything |
| **Barba.js** | Page-to-page transitions, view namespaces | Scroll, within-page animation |
| **Three.js** | Custom WebGL scenes, GLTF models, shaders | Any 2D DOM animation |
| **Spline** | Pre-built 3D scene embedding | Custom shader control |

> **Coexistence rule:** Each library owns its domain. Never overlap.  
> If two libraries could both handle something, use the one whose domain it belongs to.

## RAF (REQUESTANIMATIONFRAME) RULE

**There is one RAF loop. GSAP ticker owns it. Everything else plugs in.**

```javascript
// ✅ Correct — Three.js renders inside GSAP ticker
gsap.ticker.add((time) => {
  threeEngine.render();
  particleBackground.draw();
});

// ✅ Correct — Lenis syncs to GSAP ticker
gsap.ticker.add((time) => { lenis.raf(time * 1000); });

// ❌ Wrong — separate RAF loop
requestAnimationFrame(function loop() {
  threeEngine.render();
  requestAnimationFrame(loop);
});
```

## CONDITIONAL LOADING

Not all projects need all libraries. Load only what's required:

| Feature | Required scripts |
|---|---|
| Basic scroll reveals | GSAP + ScrollTrigger |
| SplitText hero | GSAP + SplitText |
| Smooth scroll | Lenis |
| SVG animations / counters | Anime.js |
| Page transitions | Barba.js + Lenis |
| 3D model | Three.js + GLTFLoader + DRACOLoader |
| No-code 3D scene | Spline only (exclude Three.js) |
| Full cinematic site | All libraries |

## PERFORMANCE IMPACT
- **Medium** — CDN scripts add ~400–800KB depending on libraries loaded.
- All CDN hosts (cdnjs, jsDelivr) support HTTP/2 and CDN caching.
- Scripts load in parallel when placed before `</body>` (or use `defer`).
- Three.js is the largest single dependency (~580KB minified).

## IMPLEMENTATION NOTES
- Place font `<link>` tags in `<head>` — before stylesheets
- Place script tags just before `</body>` close — or use `defer` attribute
- `type="module"` required for Spline — cannot use `defer` attribute with it
- Draco decoder URL is Google-hosted and always available:  
  `https://www.gstatic.com/draco/versioned/decoders/1.5.6/`
