**ID:** 12 | **Load order:** 12 | **Depends on:** ANIMATION, TOKENS | **Required:** desktop cinematic

## RESPONSIBILITY
Physical micro-interactions: tilt cards, magnetic elements, spotlight hover, ripple effect.

## SCOPE BOUNDARIES
- ✅ Tilt cards (3D perspective on hover)
- ✅ Magnetic elements (cursor attraction)
- ✅ Spotlight hover (radial highlight follows cursor inside element)
- ✅ Ripple click effect
- ❌ Does NOT handle navbar magnetic links (→ NAVBAR module owns those)
- ❌ Does NOT handle cursor states (→ CURSOR module)

## WHEN TO USE
Desktop creative/portfolio/agency sites where tactile interaction adds value.

## WHEN NOT TO USE
- Dashboards (tilt cards create spatial confusion in data-dense UIs)
- Mobile (all interactions auto-disabled — `pointer: fine` check)
- High-cognitive-load pages (interactions compete with content comprehension)

## TILT CARDS

```javascript
// File: scripts/interactions.js

/**
 * initTiltCards
 * 3D perspective tilt on [data-tilt] elements.
 * Mouse position drives rotation — physically real feel.
 * Desktop only (pointer: fine detection).
 */
function initTiltCards() {
  if (!window.matchMedia('(pointer: fine)').matches) return;

  document.querySelectorAll('[data-tilt]').forEach(card => {
    const maxTilt     = parseFloat(card.dataset.tiltMax || 8);     // degrees
    const perspective = parseFloat(card.dataset.tiltPerspective || 800);
    const scale       = parseFloat(card.dataset.tiltScale || 1.02);

    card.style.transformStyle  = 'preserve-3d';
    card.style.transition      = `transform ${getComputedStyle(document.documentElement)
      .getPropertyValue('--dur-fast')} ${getComputedStyle(document.documentElement)
      .getPropertyValue('--ease-out')}`;

    card.addEventListener('mousemove', (e) => {
      const rect   = card.getBoundingClientRect();
      const cx     = rect.left + rect.width  / 2;
      const cy     = rect.top  + rect.height / 2;
      const dx     = (e.clientX - cx) / (rect.width  / 2);
      const dy     = (e.clientY - cy) / (rect.height / 2);

      gsap.to(card, {
        rotateY:     dx * maxTilt,
        rotateX:    -dy * maxTilt,
        scale,
        duration:   0.4,
        ease:       'power2.out',
        transformPerspective: perspective,
        transformOrigin: 'center center',
      });
    });

    card.addEventListener('mouseleave', () => {
      gsap.to(card, {
        rotateX: 0, rotateY: 0, scale: 1,
        duration: 0.6, ease: 'elastic.out(1, 0.4)',
      });
    });
  });
}
```

**HTML usage:**
```html
<div data-tilt data-tilt-max="6" data-tilt-scale="1.02">
  Card content
</div>
```

## MAGNETIC ELEMENTS

```javascript
/**
 * initMagneticElements
 * Elements attract toward cursor within their hover zone.
 * Springs back on mouse leave — elastic.out feel.
 * Use for: large CTAs, feature icons, floating badges.
 */
function initMagneticElements() {
  if (!window.matchMedia('(pointer: fine)').matches) return;

  document.querySelectorAll('[data-magnetic]').forEach(el => {
    const strength = parseFloat(el.dataset.magneticStrength || 0.4);

    el.addEventListener('mousemove', (e) => {
      const rect = el.getBoundingClientRect();
      const x = e.clientX - (rect.left + rect.width  / 2);
      const y = e.clientY - (rect.top  + rect.height / 2);
      gsap.to(el, {
        x: x * strength, y: y * strength,
        duration: 0.4, ease: 'power2.out',
      });
    });

    el.addEventListener('mouseleave', () => {
      gsap.to(el, {
        x: 0, y: 0,
        duration: 0.7, ease: 'elastic.out(1, 0.4)',
      });
    });
  });
}
```

**HTML usage:**
```html
<button data-magnetic data-magnetic-strength="0.3">
  Get started
</button>
```

## SPOTLIGHT HOVER

```javascript
/**
 * initSpotlight
 * Radial light follows cursor inside [data-spotlight] elements.
 * Creates a "lit from inside" feel on dark cards/sections.
 */
function initSpotlight() {
  document.querySelectorAll('[data-spotlight]').forEach(el => {
    el.style.position = 'relative';
    el.style.overflow = 'hidden';

    // Create spotlight overlay
    const light = document.createElement('div');
    light.style.cssText = `
      position: absolute; inset: 0;
      background: radial-gradient(
        300px circle at var(--x, 50%) var(--y, 50%),
        rgba(255,255,255,0.06), transparent 80%
      );
      pointer-events: none; z-index: 1;
      opacity: 0; transition: opacity 0.3s;
    `;
    el.appendChild(light);

    el.addEventListener('mouseenter', () => { light.style.opacity = '1'; });
    el.addEventListener('mousemove', (e) => {
      const rect = el.getBoundingClientRect();
      light.style.setProperty('--x', `${e.clientX - rect.left}px`);
      light.style.setProperty('--y', `${e.clientY - rect.top}px`);
    });
    el.addEventListener('mouseleave', () => { light.style.opacity = '0'; });
  });
}
```

**HTML usage:**
```html
<div class="card" data-spotlight>
  Content inside the lit card
</div>
```

## RIPPLE CLICK

```javascript
/**
 * initRipple
 * Ink-drop ripple on [data-ripple] click.
 * Use on: buttons, CTAs, nav items.
 */
function initRipple() {
  document.querySelectorAll('[data-ripple]').forEach(el => {
    el.style.position = 'relative';
    el.style.overflow = 'hidden';

    el.addEventListener('click', (e) => {
      const rect = el.getBoundingClientRect();
      const ripple = document.createElement('span');
      const size = Math.max(rect.width, rect.height) * 2;

      ripple.style.cssText = `
        position: absolute;
        width: ${size}px; height: ${size}px;
        border-radius: 50%;
        background: rgba(255,255,255,0.12);
        top:  ${e.clientY - rect.top  - size / 2}px;
        left: ${e.clientX - rect.left - size / 2}px;
        transform: scale(0); pointer-events: none;
      `;
      el.appendChild(ripple);

      gsap.to(ripple, {
        scale: 1, opacity: 0,
        duration: 0.6, ease: 'power2.out',
        onComplete: () => ripple.remove(),
      });
    });
  });
}
```

## PERFORMANCE IMPACT
- **Tilt:** Low — GSAP `rotateX/Y` uses GPU compositing.
- **Magnetic:** Low — same as tilt.
- **Spotlight:** Very low — CSS variable update on mousemove.
- **Ripple:** Negligible — ephemeral DOM element.

## IMPLEMENTATION NOTES
- File: `scripts/interactions.js`
- All `mousemove` listeners are passive — no `preventDefault()` calls
- Re-initialize after Barba transitions — new page has new elements
- Tilt + Magnetic should never be applied to the same element
