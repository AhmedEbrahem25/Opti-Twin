# MODULE: BACKGROUND SYSTEM
**ID:** 09 | **Load order:** 9 | **Depends on:** TOKENS, TECH-STACK | **Required:** cinematic/ambient projects

---

## RESPONSIBILITY
The interactive ambient background engine: mouse-reactive glows, noise grain overlay,  
and optional particle field. Background is atmosphere — never content.

## SCOPE BOUNDARIES
- ✅ Radial glow field (CSS + JS lerp mouse tracking)
- ✅ Noise grain overlay (SVG-based texture)
- ✅ Particle background (canvas, optional)
- ✅ Mobile detection — full disable on touch devices
- ✅ Scroll depth variation
- ❌ Does NOT include any foreground or hero elements
- ❌ Does NOT manage z-index above 0 (background layer only)
- ❌ Does NOT include Three.js scenes (→ WEBGL module)

## WHEN TO USE
- Agency, portfolio, luxury, entertainment, AI startup sites
- Any site where atmosphere adds to the experience

## WHEN NOT TO USE
- Dashboards — background activity is distraction
- E-commerce product pages — focus must be on product
- Medical / enterprise — clinical clarity is the goal
- Low-powered devices — background is the first thing to kill

## CONFLICTS
- Background canvas must share the GSAP ticker — no separate RAF
- z-index must stay at 0 — never above content layers
- On mobile (`pointer: coarse`): disable ALL background movement

```javascript
// File: scripts/background.js

/**
 * initInteractiveBackground
 * Mouse-reactive ambient glow field.
 * Glows follow cursor at 5–8% speed — dreamlike, never distracting.
 * Completely disabled on touch devices.
 */
function initInteractiveBackground() {
  const isMobile = !window.matchMedia('(pointer: fine)').matches;
  if (isMobile) return; // No interaction on touch

  const primary   = document.querySelector('.bg-glow--primary');
  const secondary = document.querySelector('.bg-glow--secondary');
  const tertiary  = document.querySelector('.bg-glow--tertiary');

  if (!primary) return;

  // Current lerped positions
  const pos = {
    primary:   { x: 0, y: 0 },
    secondary: { x: 0, y: 0 },
    tertiary:  { x: 0, y: 0 },
  };

  // Target positions (set on mousemove)
  const target = {
    primary:   { x: 0, y: 0 },
    secondary: { x: 0, y: 0 },
    tertiary:  { x: 0, y: 0 },
  };

  // Mouse influence percentages
  // Lower = more ambient, less responsive
  const INFLUENCE = {
    primary:   0.06,
    secondary: 0.04,
    tertiary:  0.03,
  };

  document.addEventListener('mousemove', (e) => {
    const nx = (e.clientX / window.innerWidth  - 0.5) * 2; // -1 to 1
    const ny = (e.clientY / window.innerHeight - 0.5) * 2;

    target.primary.x   = nx * window.innerWidth  * INFLUENCE.primary;
    target.primary.y   = ny * window.innerHeight * INFLUENCE.primary;

    // Secondary moves in opposite axis for depth
    target.secondary.x = -nx * window.innerWidth  * INFLUENCE.secondary;
    target.secondary.y =  ny * window.innerHeight * INFLUENCE.secondary;

    target.tertiary.x  = nx * window.innerWidth  * INFLUENCE.tertiary;
    target.tertiary.y  = -ny * window.innerHeight * INFLUENCE.tertiary;
  }, { passive: true });

  // Add to GSAP ticker — one unified RAF loop
  gsap.ticker.add(() => {
    ['primary', 'secondary', 'tertiary'].forEach(key => {
      // Lerp: current moves 8% toward target per frame
      pos[key].x += (target[key].x - pos[key].x) * 0.08;
      pos[key].y += (target[key].y - pos[key].y) * 0.08;
    });

    gsap.set(primary,   { x: pos.primary.x,   y: pos.primary.y   });
    gsap.set(secondary, { x: pos.secondary.x, y: pos.secondary.y });
    gsap.set(tertiary,  { x: pos.tertiary.x,  y: pos.tertiary.y  });
  });

  // Scroll depth — glows shift slightly as user scrolls
  window.__lenis?.on('scroll', ({ progress }) => {
    gsap.to(primary,   { y: pos.primary.y   + progress * 40, duration: 2, ease: 'none', overwrite: 'auto' });
    gsap.to(secondary, { y: pos.secondary.y - progress * 60, duration: 2, ease: 'none', overwrite: 'auto' });
  });
}
```

## OPTION B: PARTICLE FIELD (Tech / SaaS / Data products only)

> **When to use:** "network / connected" metaphor brands — tech, SaaS, developer tools.  
> **When NOT to use:** Luxury, fashion, medical, editorial — too digital-feeling.

```javascript
class ParticleBackground {
  constructor(canvasSelector) {
    this.canvas = document.querySelector(canvasSelector);
    if (!this.canvas) return;
    this.ctx    = this.canvas.getContext('2d');
    this.mouse  = { x: -9999, y: -9999 };
    this.count  = window.innerWidth < 768 ? 0 : 160;   // Off on mobile
    this.connectionDistance     = 120;
    this.mouseInfluenceRadius   = 160;

    this.resize();
    this.createParticles();
    this.bindEvents();
    this.startLoop(); // Plugs into GSAP ticker
  }

  resize() {
    this.canvas.width  = window.innerWidth;
    this.canvas.height = window.innerHeight;
  }

  createParticles() {
    this.particles = Array.from({ length: this.count }, () => ({
      x:     Math.random() * this.canvas.width,
      y:     Math.random() * this.canvas.height,
      vx:    (Math.random() - 0.5) * 0.3,
      vy:    (Math.random() - 0.5) * 0.3,
      size:  Math.random() * 1.5 + 0.5,
      alpha: Math.random() * 0.4 + 0.1,
    }));
  }

  bindEvents() {
    window.addEventListener('mousemove', (e) => {
      this.mouse.x = e.clientX;
      this.mouse.y = e.clientY;
    }, { passive: true });
    window.addEventListener('resize', () => { this.resize(); this.createParticles(); });
  }

  draw() {
    const ctx = this.ctx;
    ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);

    this.particles.forEach((p, i) => {
      p.x += p.vx; p.y += p.vy;
      if (p.x < 0) p.x = this.canvas.width;
      if (p.x > this.canvas.width)  p.x = 0;
      if (p.y < 0) p.y = this.canvas.height;
      if (p.y > this.canvas.height) p.y = 0;

      const dx = this.mouse.x - p.x;
      const dy = this.mouse.y - p.y;
      const dist = Math.hypot(dx, dy);
      const boost = dist < this.mouseInfluenceRadius ? 1 - dist / this.mouseInfluenceRadius : 0;

      ctx.beginPath();
      ctx.arc(p.x, p.y, p.size + boost * 2, 0, Math.PI * 2);
      ctx.fillStyle = `rgba(255,255,255,${p.alpha + boost * 0.4})`;
      ctx.fill();

      for (let j = i + 1; j < this.particles.length; j++) {
        const q = this.particles[j];
        const cd = Math.hypot(p.x - q.x, p.y - q.y);
        if (cd < this.connectionDistance) {
          ctx.beginPath();
          ctx.moveTo(p.x, p.y); ctx.lineTo(q.x, q.y);
          ctx.strokeStyle = `rgba(255,255,255,${(1 - cd / this.connectionDistance) * 0.12})`;
          ctx.lineWidth = 0.5;
          ctx.stroke();
        }
      }
    });
  }

  startLoop() {
    gsap.ticker.add(() => this.draw()); // One RAF to rule them all
  }
}
```

## BACKGROUND PHILOSOPHY RULES

```
✅ Always:
  — Background responds to mouse at ≤8% of cursor velocity
  — Glow positions are lerped — never snap, never fast
  — Mobile: static background only — zero interactive behavior
  — Noise grain opacity stays below 0.04

❌ Never:
  — Move glows at full cursor speed
  — Let background movement distract from reading
  — Use background as a hero element
  — Add bright flashes or aggressive pulses to the background
  — Run background animation in its own RAF loop
```

---

## PERFORMANCE IMPACT
- **Radial glow (CSS only):** Near zero — GPU-composited.
- **Radial glow + JS lerp:** Low — 3 `gsap.set()` calls per tick.
- **Particle field:** Medium-high — O(n²) for connection drawing. Cap at 160 particles.
- **Noise grain animation:** Very low — steps() animation, GPU composited.

## IMPLEMENTATION NOTES
- File: `scripts/background.js`, `styles/background.css`
- Called as step 3 in `DOMContentLoaded` — before loading sequence
- Disable entirely on `data-quality="low"` (see PERFORMANCE module)
- Never show particle background on mobile — `count = 0` handles this
