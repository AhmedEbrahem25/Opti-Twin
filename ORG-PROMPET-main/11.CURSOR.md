# MODULE: CURSOR SYSTEM
**ID:** 10 | **Load order:** 10 | **Depends on:** ANIMATION, TOKENS | **Required:** desktop cinematic

---

## RESPONSIBILITY
Custom cinematic cursor: dot (snap) + ring (lag), state machine for default/hover/text states.

## SCOPE BOUNDARIES
- ✅ Cursor dot + ring HTML/CSS/JS
- ✅ State machine: default, hover, text, drag
- ✅ Element-level cursor triggers
- ✅ Mobile disable (pointer: coarse)
- ❌ Does NOT manage cursor for 3D canvas (handled by Three.js or ignored)

## WHEN TO USE
Desktop cinematic experiences — agency, portfolio, luxury, creative.

## WHEN NOT TO USE
- Mobile (auto-disabled via media query)
- SaaS dashboards — custom cursor adds friction to productivity UI
- Enterprise B2B — too playful

```css
.cursor-dot, .cursor-ring {
  position: fixed; top: 0; left: 0;
  pointer-events: none; z-index: 99999;
  transform: translate(-50%, -50%);
  opacity: 0;
  will-change: transform;
}
.cursor-dot {
  width: 6px; height: 6px;
  background: var(--text-primary);
  border-radius: 50%;
}
.cursor-ring {
  width: 36px; height: 36px;
  border: 1.5px solid rgba(255,255,255,0.5);
  border-radius: 50%;
}

/* Hide native cursor on fine-pointer devices (desktop) */
@media (pointer: fine) {
  * { cursor: none !important; }
}
```

## JAVASCRIPT

```javascript
// File: scripts/cursor.js

class CinematicCursor {
  constructor() {
    this.dot  = document.querySelector('.cursor-dot');
    this.ring = document.querySelector('.cursor-ring');
    if (!this.dot || !this.ring) return;

    this.pos      = { x: 0, y: 0 };
    this.ring_pos = { x: 0, y: 0 };
    this.visible  = false;
    this.state    = 'default';

    this.bindEvents();
    this.startLoop();
  }

  bindEvents() {
    document.addEventListener('mousemove', (e) => {
      this.pos.x = e.clientX;
      this.pos.y = e.clientY;
      if (!this.visible) {
        this.visible = true;
        gsap.to([this.dot, this.ring], { opacity: 1, duration: 0.3 });
      }
    }, { passive: true });

    // Hover state — interactive elements
    document.querySelectorAll('a, button, [data-cursor="hover"]').forEach(el => {
      el.addEventListener('mouseenter', () => this.setState('hover'));
      el.addEventListener('mouseleave', () => this.setState('default'));
    });

    // Text state — readable content
    document.querySelectorAll('p, span, h1, h2, h3, [data-cursor="text"]').forEach(el => {
      el.addEventListener('mouseenter', () => this.setState('text'));
      el.addEventListener('mouseleave', () => this.setState('default'));
    });

    document.addEventListener('mouseleave', () => {
      gsap.to([this.dot, this.ring], { opacity: 0, duration: 0.3 });
      this.visible = false;
    });
  }

  setState(state) {
    if (this.state === state) return;
    this.state = state;

    const states = {
      default: {
        dot:  { scale: 1,    opacity: 1, borderRadius: '50%' },
        ring: { scale: 1,    opacity: 1, borderColor: 'rgba(255,255,255,0.5)' },
      },
      hover: {
        dot:  { scale: 0.4,  opacity: 0 },
        ring: { scale: 2.2,  opacity: 0.8, borderColor: 'var(--accent)' },
      },
      text: {
        dot:  { scale: 6,    opacity: 0.12, borderRadius: '2px' },
        ring: { scale: 0,    opacity: 0 },
      },
    };

    const s = states[state] || states.default;
    gsap.to(this.dot,  { ...s.dot,  duration: 0.35, ease: 'power3.out' });
    gsap.to(this.ring, { ...s.ring, duration: 0.5,  ease: 'power3.out' });
  }

  startLoop() {
    gsap.ticker.add(() => {
      // Dot: snaps directly to cursor
      gsap.set(this.dot, { x: this.pos.x, y: this.pos.y });
      // Ring: lags behind — physical feel
      this.ring_pos.x += (this.pos.x - this.ring_pos.x) * 0.15;
      this.ring_pos.y += (this.pos.y - this.ring_pos.y) * 0.15;
      gsap.set(this.ring, { x: this.ring_pos.x, y: this.ring_pos.y });
    });
  }
}
```

---

## PERFORMANCE IMPACT
- **Low** — 2 `gsap.set()` calls per tick. Runs in GSAP ticker.
- `will-change: transform` on cursor elements — remove if cursor causes compositing issues.

## IMPLEMENTATION NOTES
- Instantiate in `initMainExperience()` — desktop-only check:
  ```javascript
  if (!isMobile) new CinematicCursor();
  ```
- Re-bind hover events after Barba transitions — new page DOM needs new listeners
- `data-cursor="hover"` and `data-cursor="text"` attributes available for custom elements
