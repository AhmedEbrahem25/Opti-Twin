# MODULE: INTRO SYSTEM
**ID:** 07 | **Load order:** 7 | **Depends on:** ANIMATION, SCROLL, TOKENS, TYPOGRAPHY | **Required:** cinematic projects

---

## RESPONSIBILITY
The complete 7-phase cinematic intro sequence: loading bar, ambient reveal, decorative line,  
eyebrow label, hero title, subtitle, CTA button, scroll indicator, and exit transition.

## SCOPE BOUNDARIES
- ✅ Loading bar (pre-intro asset check)
- ✅ All 7 intro phases (HTML, CSS, JavaScript)
- ✅ Intro exit (CTA click → main experience init)
- ✅ `prefers-reduced-motion` accessibility path
- ✅ Session-based one-time run logic
- ❌ Does NOT initialize the main experience (calls `initMainExperience()` which is defined in main.js)
- ❌ Does NOT control navbar (Navbar module handles its own entrance after intro exits)

## WHEN TO USE
- Creative agency sites
- Portfolio / showcase sites
- Luxury brand experiences
- Any site where "entering a world" is the intent

## WHEN NOT TO USE
- SaaS dashboards — users return daily, skip the ceremony
- E-commerce with conversion as primary goal
- Enterprise / B2B products — time to value matters
- Mobile-only experiences where load time is critical
If skipping: set `sessionStorage.setItem('intro-seen', 'true')` on first load and check it.

## CONFLICTS
- Navbar must be hidden during intro (z-index or `display: none`)
- Three.js should NOT init during intro — only fires in `initMainExperience()`
- Lenis must be initialized BEFORE intro starts (scroll may be needed during intro)

## JAVASCRIPT — 7-PHASE SEQUENCE

```javascript
// ═══════════════════════════════════════════════
//  scripts/intro.js
// ═══════════════════════════════════════════════

/*
  PHASE TIMELINE:
  ─────────────────────────────────────────────
  Phase 1 @ 0.0s   — Ambient bg breathes in (scale + opacity)
  Phase 2 @ 0.5s   — Decorative line draws L→R
  Phase 3 @ 0.8s   — Eyebrow label, letter-spacing collapses
  Phase 4 @ 1.0s   — Hero title char-by-char 3D flip
  Phase 5 @ 1.9s   — Subtitle fades through blur
  Phase 6 @ 2.5s   — CTA button slides up + glow pulse begins
  Phase 7 @ 3.2s   — Scroll indicator appears
  ─────────────────────────────────────────────
  Total pre-interaction: ~3.8s
  Reduced-motion path: instant reveal of all elements
*/

function runIntroSequence() {
  const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

  if (prefersReduced) {
    // Instant reveal — no animation, all elements visible
    gsap.set([
      '.intro-ambient', '.intro-label', '.intro-title',
      '.intro-subtitle', '.cta-btn', '.scroll-indicator'
    ], { opacity: 1, y: 0, filter: 'none', scale: 1, letterSpacing: '0.08em' });
    return;
  }

  const tl = gsap.timeline({ defaults: { ease: 'power3.out' } });

  // ── Phase 1: Ambient bg ─────────────────────
  tl.to('.intro-ambient', { opacity: 1, scale: 1, duration: 2.0, ease: 'power2.out' }, 0);

  // ── Phase 2: Decorative line ────────────────
  tl.call(() => {
    const line = document.querySelector('.intro-line');
    if (!line) return;
    gsap.set(line, { opacity: 1 });
    anime({
      targets: '.intro-line line',
      strokeDashoffset: [1440, 0],
      easing: 'easeInOutCubic',
      duration: 900,
    });
  }, [], 0.5);

  // ── Phase 3: Eyebrow label ──────────────────
  // Contrasting arrival: smallest text before largest
  tl.to('.intro-label', {
    opacity: 1,
    letterSpacing: '0.08em',
    duration: 0.7,
    ease: 'power2.out',
  }, 0.8);

  // ── Phase 4: Hero title — 3D char flip ─────
  tl.add(() => animateHeroTitle('.intro-title'), 1.0);

  // ── Phase 5: Subtitle — blur fade ──────────
  tl.from('.intro-subtitle', {
    opacity: 0, y: 18, filter: 'blur(4px)', duration: 0.9,
  }, 1.9);

  // ── Phase 6: CTA + glow pulse ──────────────
  tl.from('.cta-btn', { opacity: 0, y: 28, duration: 0.7 }, 2.5)
    .call(() => {
      // Subtle glow — draws attention without aggression
      gsap.to('.cta-btn', {
        boxShadow: `0 0 32px var(--accent-glow), 0 0 64px var(--accent-glow-lg)`,
        duration: 1.2,
        ease: 'power2.inOut',
        yoyo: true,
        repeat: -1,
      });
    }, [], 3.1);

  // ── Phase 7: Scroll indicator ───────────────
  tl.from('.scroll-indicator', { opacity: 0, y: 10, duration: 0.5 }, 3.2);

  return tl;
}

// ─── LOADING SEQUENCE ────────────────────────────
/*
  Fills loading bar, waits for document.fonts.ready,
  then calls the intro sequence via callback.
  This prevents FOUT breaking SplitText.
*/
function runLoadingSequence(onComplete) {
  const bar = document.querySelector('.loading-bar');

  // Wait for fonts — required for SplitText accuracy
  document.fonts.ready.then(() => {
    gsap.to(bar, {
      scaleX: 1,
      transformOrigin: 'left center',
      duration: 1.2,
      ease: 'power2.inOut',
      onComplete: () => {
        gsap.to(bar, { opacity: 0, duration: 0.3, onComplete });
      },
    });
  });
}

// ─── INTRO EXIT ──────────────────────────────────
/*
  On CTA click:
  1. Kill glow animation
  2. Collapse overlay: blur out, slight scale-up (camera zoom feel), fade
  3. Display: none (keep in DOM for sessionStorage skip on re-visit)
  4. Call initMainExperience() — starts Three.js, Navbar, cursor, etc.
*/
function bindIntroExit() {
  const btn = document.querySelector('.cta-btn');
  if (!btn) return;

  btn.addEventListener('click', () => {
    gsap.killTweensOf('.cta-btn');  // Stop glow pulse

    gsap.timeline()
      .to('.intro-overlay', {
        opacity:  0,
        filter:   'blur(24px)',
        scale:    1.06,   // Zoom-through feeling
        duration: 0.85,
        ease:     'power3.inOut',
      })
      .call(() => {
        document.getElementById('intro').style.display = 'none';
        sessionStorage.setItem('intro-seen', 'true');
        window.initMainExperience();
      }, [], '-=0.1');
  });
}

// ─── SESSION CHECK ──────────────────────────────
/*
  If user has seen the intro this session, skip to the main experience.
  Call this BEFORE runLoadingSequence().
*/
function checkIntroSession() {
  if (sessionStorage.getItem('intro-seen')) {
    document.getElementById('intro').style.display = 'none';
    document.querySelector('.loading-bar')?.remove();
    window.initMainExperience();
    return true; // Was skipped
  }
  return false; // Needs to run
}
```

## INTEGRATION IN MAIN.JS

```javascript
document.addEventListener('DOMContentLoaded', () => {
  gsap.registerPlugin(ScrollTrigger, SplitText, CustomEase);
  const lenis = initLenis();
  initInteractiveBackground();

  if (!checkIntroSession()) {
    runLoadingSequence(() => {
      runIntroSequence();
      bindIntroExit();
    });
  }
});
```

## PERFORMANCE IMPACT
- **Medium** — SplitText creates many DOM nodes for the title.
- After intro exit: remove `will-change` from intro elements, or leave `display:none`.
- WebGL canvas on intro (optional) is the heaviest element — disable on low-tier devices.

## IMPLEMENTATION NOTES
- File: `scripts/intro.js`
- All intro elements use `will-change: opacity, transform` — remove after exit
- CTA button label options: "Enter" · "Explore" · "Begin" · "Enter Site"
- Do not auto-play video or audio during intro — browser will block it
- `prefers-reduced-motion` path must be unconditionally fast — no delays
