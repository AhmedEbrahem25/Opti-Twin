# MODULE: TYPOGRAPHY
**ID:** 03 | **Load order:** 3 | **Depends on:** TOKENS | **Required:** always

---

## RESPONSIBILITY
Define the type system: font pairing selection, scale, weights, spacing, and line-height rules.  
Typography is the primary tool for hierarchy, emotion, and editorial character.

## SCOPE BOUNDARIES
- ✅ Font selection logic (display, body, mono)
- ✅ Typographic scale
- ✅ Letter spacing, line height, weight rules
- ✅ Google Fonts CDN link structure
- ❌ Does NOT define animation of type (→ ANIMATION module — SplitText)
- ❌ Does NOT define font tokens in CSS variables (→ TOKENS module adds `--font-*`)

## WHEN TO USE
Always — typography is load-bearing for all design.

## WHEN NOT TO USE
Never skip.

---

## FONT SELECTION PHILOSOPHY

> Do not reach for Inter, Roboto, or Space Grotesk.  
> These are defaults. Defaults are invisible. Invisible is forgettable.

### Display / Hero Font — Choose ONE
The display font carries the personality of the project. It must be distinctive.

**Serif options (luxury, editorial, fashion)**
- `Cormorant` — thin, elegant, high contrast
- `Playfair Display` — editorial authority
- `DM Serif Display` — modern serif warmth
- `Bodoni Moda` — high fashion, extreme contrast

**Sans options (tech, product, agency)**
- `Syne` — geometric with personality
- `Clash Display` — bold, contemporary
- `Cabinet Grotesk` — refined grotesque
- `Satoshi` — precision-engineered neutral
- `General Sans` — clean and confident
- `Neue Haas Grotesk` — Swiss precision (self-hosted)

### Body Font — Choose ONE
Clean, highly legible at small sizes. Warm but not distracting.
- `DM Sans` — geometric clarity
- `Outfit` — modern and open
- `Plus Jakarta Sans` — refined neutrality
- `Figtree` — friendly and precise

### Mono Font — Choose ONE
Used for labels, code, eyebrow text.
- `JetBrains Mono` — developer authority
- `Fira Code` — legible, character
- `Geist Mono` — Vercel's choice — clean and modern

## GOOGLE FONTS CDN PATTERN

```html
<!-- Load in <head> — ONE pairing per project -->
<!-- Format: display font + body font + mono font -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- Example: Agency/Creative project -->
<link href="https://fonts.googleapis.com/css2?family=Syne:wght@400;700&family=DM+Sans:wght@300;400;500&family=JetBrains+Mono:wght@400&display=swap" rel="stylesheet">

<!-- Example: Luxury/Fashion project -->
<link href="https://fonts.googleapis.com/css2?family=Cormorant:ital,wght@0,300;0,600;1,300&family=DM+Sans:wght@300;400&family=JetBrains+Mono:wght@400&display=swap" rel="stylesheet">
```

> Load max 2 weights per font. Always include `display=swap` to prevent FOUT.

## CSS FONT VARIABLES

Add to `styles/variables.css` (TOKENS module file):

```css
:root {
  --font-display: 'YOUR_DISPLAY_FONT', serif;   /* or sans-serif */
  --font-body:    'YOUR_BODY_FONT', sans-serif;
  --font-mono:    'YOUR_MONO_FONT', monospace;
}
```

## TYPE SCALE (Modular — 1.333 ratio base)

```css
/* styles/typography.css */

/* ─── SCALE ─────────────────────────────────────── */
/* px: 11 · 13 · 14 · 16 · 20 · 24 · 32 · 48 · 64 · 96 · 128 · 160 */

.text-2xs  { font-size: 11px; }
.text-xs   { font-size: 13px; }
.text-sm   { font-size: 14px; }
.text-base { font-size: 16px; }
.text-lg   { font-size: 20px; }
.text-xl   { font-size: 24px; }
.text-2xl  { font-size: 32px; }
.text-3xl  { font-size: 48px; }
.text-4xl  { font-size: 64px; }
.text-5xl  { font-size: 96px; }
.text-6xl  { font-size: 128px; }
.text-7xl  { font-size: 160px; }

/* ─── HERO / DISPLAY ─────────────────────────────── */
.type-hero {
  font-family: var(--font-display);
  font-size: clamp(56px, 10vw, 160px);
  font-weight: 700;
  letter-spacing: -0.04em;
  line-height: 0.95;
  color: var(--text-primary);
}

/* ─── SECTION HEADING ────────────────────────────── */
.type-heading {
  font-family: var(--font-display);
  font-size: clamp(32px, 5vw, 80px);
  font-weight: 700;
  letter-spacing: -0.03em;
  line-height: 1.05;
  color: var(--text-primary);
}

/* ─── SUBHEADING ─────────────────────────────────── */
.type-subheading {
  font-family: var(--font-body);
  font-size: clamp(16px, 2vw, 24px);
  font-weight: 400;
  letter-spacing: 0em;
  line-height: 1.5;
  color: var(--text-secondary);
}

/* ─── BODY ───────────────────────────────────────── */
.type-body {
  font-family: var(--font-body);
  font-size: 16px;
  font-weight: 400;
  letter-spacing: 0em;
  line-height: 1.7;
  color: var(--text-secondary);
}

/* ─── LABEL / EYEBROW ────────────────────────────── */
.type-label {
  font-family: var(--font-mono);
  font-size: 11px;
  font-weight: 400;
  letter-spacing: 0.12em;
  text-transform: uppercase;
  color: var(--text-tertiary);
}

/* ─── BASE RESET ──────────────────────────────────── */
body {
  font-family: var(--font-body);
  font-size: 16px;
  color: var(--text-secondary);
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  text-rendering: optimizeLegibility;
}

h1, h2, h3 {
  font-family: var(--font-display);
  color: var(--text-primary);
}
```

## TYPOGRAPHIC RULES

| Property | Display/Hero | Headings | Body | Labels |
|---|---|---|---|---|
| `letter-spacing` | `-0.03em` to `-0.05em` | `-0.02em` to `-0.03em` | `0` | `+0.08em` to `+0.12em` uppercase |
| `line-height` | `0.95–1.05` | `1.1–1.2` | `1.6–1.75` | `1.4` |
| `font-weight` | 700 | 600–700 | 300–400 | 400 |
| Max weights loaded | 2 | — | 2 | 1 |

> **Rule:** Maximum 2 weights per font family. More = slower load, less harmony.  
> **Rule:** Never mix two display fonts. One display, one body, one mono.

## FOUT PREVENTION

SplitText animations (→ ANIMATION module) will break if fonts aren't loaded.

```javascript
// In INTRO module loading sequence:
document.fonts.ready.then(() => {
  runLoadingSequence(() => runIntroSequence());
});
```

This ensures SplitText animates rendered glyphs, not fallback font chars.

## PERFORMANCE IMPACT
- **Low** — Fonts are loaded from CDN with `display=swap`.
- Limit to 3 font families, 2 weights each = ~6 font files.
- Preconnect to `fonts.googleapis.com` and `fonts.gstatic.com` in `<head>`.

## IMPLEMENTATION NOTES
- File: `styles/typography.css`
- Load after `variables.css`
- Font `<link>` tags must be in `<head>` before any stylesheet
- For production: self-host fonts via `fonttools` or `fontsquirrel` for zero CDN latency
