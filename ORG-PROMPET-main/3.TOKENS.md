# MODULE: TOKENS
**ID:** 02 | **Load order:** 2 | **Depends on:** IDENTITY | **Required:** always

---

## RESPONSIBILITY
Define the complete design token system: colors, spacing, easing, shadows, radii, durations.  
This is the **single source of truth** for all visual values. No other module hardcodes values.

## SCOPE BOUNDARIES
- ✅ CSS custom properties (all `:root` variables)
- ✅ Color system + accent table by project type
- ✅ Spacing scale, radius scale, shadow scale
- ✅ Easing functions + duration scale
- ✅ Navbar-specific tokens
- ❌ Does NOT define typography scale (→ TYPOGRAPHY module)
- ❌ Does NOT define component-level styles (→ individual modules)
- ❌ Does NOT define motion behavior (→ ANIMATION module)

## WHEN TO USE
Always. Every visual module depends on this.

## WHEN NOT TO USE
Never skip.

## CONFLICTS
- None. This module is upstream of all others.

## COLOR PHILOSOPHY

- **Background base:** `#050505` — near-black. Never pure `#000`.
- **Surface scale:** Steps from `#080808` → `#161616`. Never jump to white.
- **Borders:** Low-opacity white — never colored borders on dark backgrounds.
- **Accent:** Context-driven. Match the project's DNA. See table below.

### Accent Color by Project Type

| Project Type | Primary Accent | Secondary | Glow (15% opacity) |
|---|---|---|---|
| Medical / Health | `#00ff88` | `#00cc6e` | `rgba(0,255,136,0.15)` |
| Tech / SaaS | `#6366f1` | `#818cf8` | `rgba(99,102,241,0.15)` |
| Luxury / Fashion | `#c9a96e` | `#e8d5b0` | `rgba(201,169,110,0.12)` |
| Agency / Creative | `#ff3c00` | `#ff6b3d` | `rgba(255,60,0,0.15)` |
| Finance / Fintech | `#22d3ee` | `#67e8f9` | `rgba(34,211,238,0.12)` |
| Entertainment | `#a855f7` | `#c084fc` | `rgba(168,85,247,0.15)` |
| Developer Tools | `#22c55e` | `#4ade80` | `rgba(34,197,94,0.15)` |
| AI / Research | `#f59e0b` | `#fbbf24` | `rgba(245,158,11,0.12)` |

> Set `--accent` to your project's primary accent. Derive the rest from it.  
> Glow values = accent at 8–15% opacity. Never brighter.

## MASTER CSS TOKENS

```css
/* ═══════════════════════════════════════════════════ */
/*  FAEA DESIGN TOKENS — shadcn/ui influenced          */
/*  Place in: styles/variables.css                     */
/*  Load before all other stylesheets                  */
/* ═══════════════════════════════════════════════════ */

:root {

  /* ─── BACKGROUNDS ─────────────────────────────── */
  --bg:       #050505;   /* Page base — never #000 */
  --bg-100:   #080808;
  --bg-200:   #0d0d0d;
  --bg-300:   #111111;
  --bg-400:   #161616;   /* Elevated surfaces */

  /* ─── BORDERS ──────────────────────────────────── */
  --border:         rgba(255,255,255,0.06);   /* Resting */
  --border-hover:   rgba(255,255,255,0.12);   /* Hovered */
  --border-focus:   rgba(255,255,255,0.24);   /* Focused */

  /* ─── ACCENT — REPLACE PER PROJECT ────────────── */
  --accent:          /* e.g. #6366f1 */;
  --accent-dark:     /* ACCENT -20% brightness */;
  --accent-light:    /* ACCENT +20% brightness */;
  --accent-glow:     /* ACCENT at 0.15 opacity */;
  --accent-glow-lg:  /* ACCENT at 0.08 opacity */;

  /* ─── TEXT ──────────────────────────────────────── */
  --text-primary:   #f5f5f5;   /* Headings, active UI */
  --text-secondary: #888888;   /* Body, descriptions */
  --text-tertiary:  #444444;   /* Labels, metadata */
  --text-muted:     #2a2a2a;   /* Disabled, placeholder */

  /* ─── RADIUS — shadcn/ui scale ─────────────────── */
  --radius-xs:   4px;
  --radius-sm:   8px;
  --radius-md:   12px;
  --radius-lg:   16px;
  --radius-xl:   24px;
  --radius-2xl:  32px;
  --radius-full: 9999px;

  /* ─── SPACING — 4pt grid ────────────────────────── */
  --space-1:   4px;
  --space-2:   8px;
  --space-3:   12px;
  --space-4:   16px;
  --space-5:   20px;
  --space-6:   24px;
  --space-8:   32px;
  --space-10:  40px;
  --space-12:  48px;
  --space-16:  64px;
  --space-20:  80px;
  --space-24:  96px;

  /* ─── EASING ─────────────────────────────────────── */
  --ease-out:       cubic-bezier(0.16, 1, 0.3, 1);
  --ease-in-out:    cubic-bezier(0.87, 0, 0.13, 1);
  --ease-spring:    cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-bounce:    cubic-bezier(0.68, -0.55, 0.265, 1.55);

  /* ─── DURATIONS ──────────────────────────────────── */
  --dur-instant: 0.1s;
  --dur-fast:    0.2s;
  --dur-mid:     0.4s;
  --dur-slow:    0.7s;
  --dur-cinema:  1.2s;

  /* ─── SHADOWS ────────────────────────────────────── */
  --shadow-sm:   0 1px 3px rgba(0,0,0,0.4), 0 1px 2px rgba(0,0,0,0.3);
  --shadow-md:   0 4px 16px rgba(0,0,0,0.5);

  --shadow-glow: 0 0 24px var(--accent-glow), 0 0 48px var(--accent-glow-lg);

  /* ─── NAVBAR TOKENS ──────────────────────────────── */
  --nav-height:    72px;

  --scroll-progress: 0;
}
```

## ADAPTIVE TOKEN OVERRIDES (Project Modes)

Project modes (see MODES module) apply overrides via `[data-mode]` selectors:

```css
/* Example: Luxury mode overrides */
[data-mode="luxury-cinematic"] {
  --dur-cinema: 1.8s;
  --dur-slow:   1.1s;
  --ease-cinematic: cubic-bezier(0.16, 1, 0.3, 1);
}

/* Example: Dashboard mode overrides */
[data-mode="dashboard"] {
  --dur-fast:  0.15s;
  --dur-mid:   0.25s;
  --dur-slow:  0.4s;
}
```

## TOKEN DISCIPLINE RULES

1. **Never hardcode a hex value** in a component stylesheet. Use `var(--token)`.
2. **Never use `#000` or `#fff`** — use `--bg` and `--text-primary`.
3. **Accent touches**: Max 3 accent-colored elements per viewport at once.
4. **Derive glow from accent** — never set a glow color independently.
5. **Border hover values** are exactly 2x the resting border opacity.
